This project implements an online marketplace, UrbanFood, designed to connect urban farmers and local producers with consumers interested in purchasing fresh food and products. The platform offers a variety of products, including fruits, vegetables, dairy products, baked goods, and handmade crafts.

__Features__

__Product Catalog:__ View and search products in categories like fruits, vegetables, dairy, baked goods, and handmade crafts.

__Supplier Profiles:__ Suppliers can create and manage their profiles, listing their products.

__Customer Management:__ Customers can create accounts, browse products, and place orders.

__Order Management:__ Track customer orders, update payment statuses, and manage deliveries.

__Payments:__ Handle payments and order transactions securely.

__Product Reviews:__ Customers can leave feedback and ratings for products.

__NoSQL Database Integration (MongoDB):__ Store product reviews and customer feedback in MongoDB for efficient search and data retrieval.

__Tech Stack__

__Backend:__ Java (Spring Boot)

__Database:__ Oracle (RDBMS) for transactional data and MongoDB for user-generated content.

__Frontend:__ HTML, CSS, JavaScript (for the e-commerce website interface)

__Additional Tools:__ Oracle PL/SQL for database queries, MongoDB for managing user reviews.
